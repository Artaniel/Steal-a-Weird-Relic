## Итерация 2 — Traps / Hearts / Escape (День 2)
TrapSystem, здоровье игрока, побег.

[]2.1 Модуль TrapSystem с 4 типами: laser, camera, plate, drone — интерфейс ITrap с методом активации/детекта игрока.
[]2.2 Laser: линия/зона детекта, вкл/выкл по паттерну.
[]2.3 Camera: конус обзора, детект по нахождению в конусе N времени.
[]2.4 Plate: триггер по весу/нажатию (наступил — сработало).
[]2.5 Drone: патрулирующий агент с зоной детекта (путь по вейпоинтам либо NavMesh — на выбор, без арта, примитив-капсула).
[]2.6 Trap seed фиксируется на старте run и не меняется до рестарта (детерминированный паттерн ловушек в рамках одного захода).
[]2.7 Trap telegraph: визуальный/логический сигнал за ≥500 мс до срабатывания урона (сам сигнал — минимальный, без арта).
[]2.8 Health/Hearts: 3 сердца, потеря сердца при попадании в ловушку.
[]2.9 При потере сердца — возврат игрока к двери текущей комнаты (не к началу run).
[]2.10 При 0 сердец — heist fail, переход в Result (failed).
[]2.11 Escape-фаза: таймер 20 секунд после выбора реликвии.
[]2.12 На escape активные ловушки меняются (реролл/смена паттерна ловушек комнаты).
[]2.13 Assist route: после двух ошибок в рамках run — предложить безопасный путь (флаг на UI/pathfinder, сама подсветка — минимальная).

## Итерация 4 — Levels 1-4 / heist flow / UI wiring (День 4)
Оркестрация run'а из комнат, состояние потока, минимальная UI-обвязка (без визуального дизайна).

[]4.1 RoomDirector: собирает heist run из модульных данных — список комнат (3-5) с типами ловушек по музею.
[]4.2 HeistFlow как state machine: TargetSelect → Rooms(1..N) → RelicChoice → Escape → Result.
[]4.3 RelicChoice: показ трёх витрин (случайные реликвии по rarity-весам музея), выбор одной.
[]4.4 Result: success/failed веткование, передача данных в RelicService/Economy.
[]4.5 UI flow wiring по схеме из ГДД: Boot → Museum/Offline Claim → Target Select → Heist Rooms → Relic Choice → Escape → Result → Display Hall/Album → Next Target (хук в UI-заглушки, сам визуал — не наша часть).
[]4.6 Собрать музеи 1-4 как данные (rooms count, ловушки, target time) по GD-таблице музеев.
[]4.7 Target Select: список из трёх музеев на выбор игрока (пока первые 4).
